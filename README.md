# Whisper — локальная расшифровка для Windows

Утилита расшифровывает аудио и видео на этом компьютере и сохраняет один файл: `…_расшифровка.txt`. В нём есть текст, тайм-коды и, при включённой диаризации, имена спикеров.

Запись не отправляется в сторонние сервисы. Единственное сетевое действие — первое скачивание модели Whisper.

## Первый запуск

1. Откройте `setup.bat` двойным щелчком и дождитесь строки `Done`.
2. Если Python 3.10–3.13 не установлен, установщик сам поставит Python 3.13 через Windows Package Manager. Если Windows Package Manager отсутствует, он откроет официальную страницу Python и попросит запустить `setup.bat` повторно после установки.
3. Установщик сразу добавляет транскрибатор, конвертер MP3 и определение спикеров.
4. Откройте `start.bat`, выберите запись, папку для результата и нажмите «Расшифровать».

По умолчанию TXT сохраняются в `OneDrive\Documents\DC\Транскрипты\Выводы` текущего пользователя. Папка создаётся автоматически; при необходимости её можно изменить в окне.

Для любой совместимой NVIDIA-карты программа сначала пытается использовать GPU. Если CUDA не запустится, она покажет статус и автоматически перейдёт на процессор — запись не потеряется.

## Передача другому человеку

В папке есть оба режима: окно Whisper и кнопка «Видео → MP3», которая открывает локальный конвертер в браузере. Для подготовки архива запустите в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\package_release.ps1 -Version 0.2.0
```

В папке `dist` появится ZIP только с исходниками и установочными файлами. В него не попадут виртуальное окружение, скачанные модели, записи и токен Hugging Face. Такой архив можно прикрепить к GitHub Release или хранить в приватном репозитории.

Это Windows-версия. На компьютере получателя нужен интернет только на время установки и первого скачивания моделей: `setup.bat` при необходимости сам ставит Python 3.13. Затем он выбирает вариант для NVIDIA: при наличии `nvidia-smi` ставит CUDA-библиотеки и CUDA PyTorch; на AMD, Intel или компьютере без NVIDIA приложение работает на CPU. Конвертер видео в MP3 работает в обоих вариантах.

Получателю достаточно распаковать ZIP, запустить единственный установщик `setup.bat`, а затем `start.bat`. Токен Hugging Face для определения спикеров каждый пользователь вводит свой.

Для установки скачивайте именно ZIP из раздела **Releases**. Ссылка GitHub **Code → Download ZIP** предназначена для просмотра исходников и не является готовым установочным архивом.

## Настройки

- **large-v3-turbo** — вариант по умолчанию: очень хорошее качество и высокая скорость на RTX 5080. При первом запуске понадобится примерно 1,5 ГБ свободного трафика и диска.
- **large-v3** — немного более тщательная, но медленнее и больше.
- **medium/small/base** — для быстрых черновиков или если не хватает видеопамяти.
- **Подсказка** — вставьте редкие имена, бренды и специальную терминологию через запятую. Это помогает модели писать их правильнее.
- Фильтр пауз обычно улучшает записи с тишиной и фоновым шумом. Если речь не находится, снимите галочку и повторите.

## Спикеры в расшифровке

Программа умеет проставлять говорящего для каждой фразы: `Спикер 1`, `Спикер 2` и так далее. Если заранее указать имена в порядке их первого появления (например, `Антон, Мария`), они сразу попадут в TXT вместо технических меток.

Если поле имён оставить пустым, программа также попробует автоматически заменить метку. Она понимает явное представление («меня зовут Антон», «я — Антон») и известные русские имена в диалоговых обращениях вроде «Влад, что думаешь?», если после них отвечает другой голос. Для надёжности нужно минимум два одинаково привязанных обращения; слова «Да» или «Прости» именами не считаются.

Это определение голосов внутри одной записи: один и тот же голос получит одну и ту же метку на протяжении разговора. Чтобы модель называла человека по имени, укажите имя вручную — программа не угадывает личность человека по голосу.

### Однократная подготовка

Компонент спикеров уже ставится внутри `setup.bat`; для NVIDIA это может добавить около 3 ГБ загрузки PyTorch. Затем:

1. В браузере откройте [модель Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1), войдите в бесплатный аккаунт Hugging Face и примите условия доступа.
2. На странице [токенов Hugging Face](https://huggingface.co/settings/tokens) создайте токен с правом `Read`.
3. В окне Whisper оставьте включённым «Определять спикеров», вставьте токен и запустите расшифровку.

Токен сохраняется в защищённом хранилище Windows Credential Manager и автоматически подставляется при следующем запуске. После загрузки и модель, и расшифровка работают на вашем ПК.

## Поддерживаемые файлы

MP3, WAV, M4A, AAC, OGG, OPUS, FLAC, WMA и распространённые видеофайлы: MP4, MKV, MOV, AVI, WebM, MPEG.

## Видео → MP3 в браузере

Откройте `audio_converter.bat`. В браузере появится локальная страница: выберите видео, укажите качество и нажмите «Сделать MP3». Готовый файл можно скачать со страницы; его копия также появится в папке `Готовые MP3` рядом с программой.

Страница доступна только на этом компьютере по адресу `127.0.0.1`. Адрес открывается автоматически и использует свободный порт, поэтому не конфликтует с другими локальными приложениями. Конвертацию выполняет FFmpeg; после первого запуска `setup.bat` не нужны дополнительные установки.

## Если не запускается на видеокарте

1. Обновите драйвер NVIDIA через NVIDIA App.
2. Запустите `setup.bat` повторно: он установит нужные CUDA-библиотеки в отдельную папку программы.
3. Если в интерфейсе всё равно указан CPU, программа работает корректно, но медленнее. Пришлите текст ошибки из окна — по нему можно точно подобрать совместимые библиотеки.

## Чем этот вариант отличается от присланного скрипта

Исходный файл использует `mlx-whisper`, а это библиотека для Mac на Apple Silicon. Здесь используется `faster-whisper`, рассчитанный в том числе на Windows и NVIDIA CUDA. Он сам обрабатывает длинные файлы, поэтому не нужно предварительно делить запись на части и вручную сдвигать тайм-коды.
